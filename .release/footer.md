## Installation

Home Assistant **2025.2** or newer, Stalwart **0.16** or newer, and
[Log Notifier](https://github.com/stefgo/ha-log-notifier) for the messages.

**HACS → ⋮ → Custom repositories** → `stefgo/ha-dmarc-monitor`, category **Integration** →
*Add*. Then install "DMARC Monitor" and restart Home Assistant.

Full documentation is in the [README](https://github.com/stefgo/ha-dmarc-monitor#readme).
